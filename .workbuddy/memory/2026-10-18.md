## 跑团（session）模块优化方案：使其成立为「跑团帷幕」（方案产出，未实现）

### 现状诊断（代码实证）

### 方案骨架（四层）
- **L0 数据**：Event 增 `visibility: public|secret`（缺省 public，向后兼容不需迁移）；揭示 = append 一条 `chat.reveal` 事件 + 原事件标 revealed，历史只追加不改；启用 `Session.state` 存 tracker/rule_set/scene；新增 kind `combat.turn`/`state.change`/`scene.set`。

- **L2 帷幕本体**：`Ctrl+G` 切全景/玩家视图；先攻条（当前回合高亮，next 推进并 append combat.turn）；PartyPanel → 角色卡面板（HP 条 / 状态标签 / 快捷检定按钮）；随机表 `tables/<id>.json`（1d100 区间 → 条目）。

## 结构模块 bug 修复：「选什么类型都变旁白」(2026-10-18 二次)

### 根因
- `ScriptStructuredEditor` 是 `content` 受控组件，每次编辑都 `serializeScript→parseScript` 往返来重渲染。空字段/输入中途的退化文本（如空说话人 say 序列化为 `****：`）解析器无法识别，被「不认识的语法当 narration」规则误判为旁白（`>` 前缀）。所以无论选对话/动作/选项/背景，空行都会退化成旁白、语法被追加到 `>` 后（对白即 `>****:`）。

### 修复
- **结构化编辑器持有权威行列表**（`ScriptStructuredEditor.tsx`）：内部 `parsed` state，编辑只 `setParsed` + 序列化回写 `onChange`；仅当 content 非自身回写（外部/源码互编）才重新解析（`lastEmittedRef` 守卫）。不再用 serialize→parse 驱动自身渲染。父级 `key` 已按 `文件:模式` 重挂载，外部变更极少。
- **解析器容忍退化空字段**（`parser.ts`）：say 允许空说话人+可选冒号（`****：`/`****`→say）；`@bg|@actor` 允许空值（`(?:\s+(.*))?`，并 `(at[2]??"")` 兜底裸 `@bg`）；choice 允许空标签、且裸 `*` 识别为空 choice（`* ` 经 trim 退化成 `*`）；action 允许空文本（`**`→action）。

### 验证
- `npx tsc --noEmit` 通过；`parser.test.ts` 新增「退化空字段往返」「`****：` 解析回 say」用例；`vitest run src/features/story` 17 用例全过；`vite build` 验证中。
