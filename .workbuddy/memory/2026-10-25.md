## UI 重设计第 1、2 步：token 层 + 组件层（用户选了「先做 1、2」，第 3 步重画视觉未做）

起点数据：1298 处 `style={{}}` 内联样式散在 150/168 个 tsx；
`src/components/ui/` 只有 7 个组件；颜色 token 有 130+ 个，
**spacing 与字号 token 一个都没有** —— 这就是「换肤能换、改版式改不动」的根因。

**关键发现：病灶不是缺组件，是组件建了没人用。**
`EmptyState` 只有 2 处引用，而 4 个文件一字不差地抄了它那份内联样式；
`SectionLabel` 有 15 处引用，但另有 25 处分区标题仍在抄内联。
原因之一是导入要写深路径 `from "../../components/ui/EmptyState"`。

### 做了什么
- `index.css` `:root` 加 spacing（`--sp-0..16`）+ type scale（`--fs-xs..3xl`）+ 行高。
  **刻意不进主题预设** —— 主题只管配色（`ThemeDef.variables` 覆盖式，缺失回落 `:root`）。
  档位取自真实统计，不拍脑袋：字号 12=239 处 / 11=183 / 10=80 / 13=48。
- `input[type=checkbox|radio] { accent-color: var(--accent-gold) }` 全局化，
  消掉 18 处内联 `accentColor`。
- 新建 `components/ui/index.ts` barrel + `Stack.tsx`（`Stack`/`Row`，带 gap 参数）。
  已有 `components/field/` 7 个字段组件，不需要再造 Field。
- CSS 工具类：`.grow` `.fill` `.muted` `.truncate` `.nowrap` `.list-reset`。
  **删掉了** `.row/.stack/.spacer/.secondary/.mono/.title-font/.badge` ——
  它们的重复块都夹带其他属性，无精确匹配点，留着就是死代码；
  带参数的布局改用 `Stack`/`Row` 组件。
- 机械替换 74 处（脚本做，tsc+vitest+build 兜住）；EmptyState 4 处手工换。
  内联样式 1298 → 1224。

### 两个脚本（防漂移闸门，与 audit-deadcode.mjs 同思路）
- `scripts/audit-ui-tokens.mjs`：统计裸数值与 token 覆盖率（现 间距 96.5% / 字号 98.5%），
  `--strict` 接 CI。
- `scripts/apply-ui-classes.mjs`：把语义等价的内联换成类。
  **只做完全等价的替换，多一个属性都不换，宁可漏不可错**；遇已有 className 就跳过
  （两个 className 属性后者会静默覆盖前者）。

### 踩的坑（别再犯）
1. `style={{` 的括号计数要从第一个 `{` 开始（偏移 6，不是 7）。
   早期版本少算一层，替换后残留 52 个 `className="muted"}`，靠 tsc 才发现。
   已写进脚本注释。
2. Bash heredoc 写含 `\d` 的正则会被转义搞坏 —— 用 Write 工具写脚本，别用 heredoc。
3. 删上游会暴露新死代码（`withoutExt`→`extname`），替换完必须复跑审计，一轮不够。

### 留作下一批
- `.truncate` 28 处：实际块都夹带其他属性（flex/minWidth/fontSize…），
  需要「从块中抽走三个属性并合并 className」的部分替换，风险高于收益，没做。
- `SectionLabel` 25 处：原内联缺 `marginBottom`，而组件默认 4px，
  批量换会改变布局 → 必须人工逐个判断 variant，不能脚本化。
- 剩余 `.grow` 19 / `.muted` 15 / `.fill` 14 / `.list-reset` 7 同理是「夹带属性」的不等价块。

### 顺带修的文档漂移
DESIGN §9 原写「`<LabeledBlock>`」——代码里根本不存在这个组件。
§9 已重写为「token → 类 → 组件」三层约定 + 选择标准 + 不抽清单 + 闸门脚本。

## UI 第 3 步：外壳观感层（顶栏 / 侧栏 / 状态栏 / 菜单 / 列表）

### **先修了一个让前两步结论失真的 bug**
`apply-ui-classes.mjs` 干跑一直是 **0 处**，不是「已经没得改」，是解析错了：
块扫描从偏移 6（第一个 `{`）起，收尾 j 停在外层 `}`，于是 `raw` 把**内层 `}` 也带进来**，
归一化后每条指纹都多一个 `}` → 全表匹配 0。修法：`norm()` 末尾剥 `}`。
修完立刻命中 25 处。

**连带后果：`.spacer / .mono / .secondary` 当初被删是误判** —— 判定依据是
「匹配数 0，没有精确匹配点」，而那是 bug 造成的假象。现已补回 CSS
（分别命中 4 / 6 / 5 处），DESIGN §9.4 的「Mono 不抽」已划掉并注明作废原因。
教训：**脚本报「0」先怀疑脚本，不要先下产品结论。**

### 新增的外壳类（观感只定义一次）
`.topbar` `.brand-mark` `.welcome-brand` `.menu-trigger` `.menu` `.menu-item`
`.menu-sep` `.nav` `.nav-item`(`.is-active`/`.is-collapsed`) `.nav-stat`
`.statusbar` `.status-action` `.panel` `.list-item` `.btn-sm`
`--menu-w` / `--shadow-pop` 两个 token。

**真正改变观感的只有两条**（其余是等价搬迁）：
1. **`:focus-visible` 金环** —— 此前全站没有任何焦点样式，Tab 过去看不出落点。
   只收 `button/a/select/[role=button]/[tabindex]`，**不含 input**（它已有 border-color 指示，再加是噪声）。
2. **悬停态下沉 CSS** —— `.nav-item / .list-item / .menu-item` 的 hover 取代了
   `onMouseEnter` 手改 style，顺带删掉 TopBar 与 Workspace 里两个 hover `useState`。

激活指示条用 `border-left: 2px solid transparent` 占位再换色 —— 否则选中瞬间文字横移 2px。

### 脚本能力扩展
`apply-ui-classes.mjs` 现在支持：命中时若标签已有**字面** `className` 就**并进去**
（`.btn` → `.btn btn-sm`）；`className={…}` 表达式改不动，跳过。
另加组合指纹 `grow truncate`（弹性+截断五属性，拆开各自都匹配不上）。
`accent-color` 全局规则补 `input[type=range]`，消掉最后 2 处内联。
